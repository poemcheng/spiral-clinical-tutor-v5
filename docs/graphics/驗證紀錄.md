## 重現

```sh
python -m pip install -r requirements-graphics.txt
python -m unittest discover -s tests -p test_graphics.py -v
node --check frontend/graphics/app.js
node --test tests/frontend/*.test.mjs
npm --prefix tests/graphics-ui ci --no-audit --no-fund
python tools/check_graphics_ui.py
```

DOM測試依賴與鎖檔獨立放在tests/graphics-ui，未改動原應用的Node套件版本。CI工作流程為graphics-checks.yml。
