# v5.6.0 講師影片庫與完整操作錄影

依使用者指定，以職種配對適合講師，涵蓋全部適用情境。48 組導讀各有 3 部影片，合計 144 部有聲 MP4：9 情境、39 組職類任務，以及 9 組社工協作導讀。8 位既有講師均納入。

## 角色、情境與教學目的

本職類已有角色時配對該職類講師。語言、聽力、呼吸治療、醫事檢驗及臨床心理等尚無專屬角色的職種，採陳醫師明確標示「跨專業案例導讀」，只介紹來源任務與交接，不冒充該職類或示範其專屬操作。何社工限家庭溝通、支持與資源協作。未虛構專業資格。

每組依來源教案分為「情境與觀察目標」、「職類任務導讀」、「交接與練習目的」。影片為 Level 1–5 共用基礎導讀；互動難度、個人弱項與當級任務以目前教案文字為準，不能把共用影片宣稱成個人化評量。

使用非真人掃描的既有 3D 角色、轉頭、眨眼、手勢及聲音驅動嘴型。角色為圖卡擬合立體模型，不能宣稱是完全相同的真人級外觀。Windows 本機男女聲逐段檢查，聲音身分及角色模型、文字來源 SHA256 均記錄於目錄。

腳本保留教學情境、缺少資訊與專業界線，不新增個案檢查數值、處方或實際已完成的技能。肌少症教案顯示 AWGS 2019／2025 差異提醒；來源與教學目的已核對，臨床內容仍待職類教師正式核定。

## 播放與本機生成

登入 Step 3 後可直接播放已發布 MP4，支援 `playsinline` 與 HTTP Range。影片按教案、職種及講師配對；來源或模型雜湊不符時不供應舊版本。各級補強模組仍依累積教材等級開放，沒有利用公開影片繞過伺服器的模組權限。

遠端、手機與平板不啟動生成。只有 localhost／127.0.0.1／::1 的本機入口提供當輪生成控制；遠端舊客戶端要求生成時，已有素材就回傳已發布狀態，沒有素材則明示需本機生成後同步。這是功能分流，並非將 Host 判斷當成權限邊界；所有學員 API 仍驗證登入與訓練所有權。

生成共用素材不讀取學員資料庫：

```powershell
.venv/Scripts/python.exe tools/build_lecture_library.py --workers 2
.venv/Scripts/python.exe tools/verify_lecture_library.py --strict --enrich-voices
.venv/Scripts/python.exe tools/prepare_publication.py
```

第一次需本機 FFmpeg、HyperFrames、已安裝的繁體中文男女聲與現有角色素材。重跑會依內容雜湊沿用完成項目，只新增或重建改變的項目。影片儲存在 `data/public_lectures`，包含 MP4、來源腳本與索引。

未來新增共用影片：本機生成、完成來源／臨床內容覆核與影音檢查，再以新版本封存並上傳 GitHub Release 的 `public-assets.zip` 和 `public-assets-manifest.json`。更新預設素材版本及主機素材後，手機就能直接播放。已發行版本保持不可變。沒有設定背景自動上傳，也不把含學員弱項、對話或成績的當輪私有影片直接公開。

## 完整操作影片

`v5.6.0-full-workflow-local.mp4` 為本機完整影像版，含原始授權教材，只留在本機交付。`v5.6.0-full-workflow-public.mp4` 為公開版，逐畫面遮蔽原始一般／環景影片、骨架來源影像；圖卡與新生成講師影片可公開。公開素材不含實拍原片、資料庫、學員資料、私鑰與來源文件。

由 CUA 實際操作擷取畫面，加入中文解說、字幕與閱讀停格。入口及講師播放段落有補錄，主訓練、教師覆核及學員查看均使用同一筆第一輪示範紀錄。影片包含：

1. 登入、職種、情境、自評與五級累積教材。
2. 已發布講師影片原速含聲播放與可讀文字稿。
3. 一般影片 ROI、180 格骨架分析、原圖／模型切換、動作意義與學員保存。
4. 四部環景入口、角色會談與原生 H5P 重練／安全結尾／一般結尾。
5. 兩輪 STT → Ollama → 對應男聲 TTS → 自動接續收音，保留約 133 秒實際等待及音訊。
6. 來源紀錄、四項決策原地保存、SBAR、測驗與成果。
7. 教師查看證據，分別保存分支、逐格及正式回饋；學員重新登入並回看同一輪三種回饋。

語音輸入是明示的合成測試音源，兩輪通過不等於 iPhone 真人麥克風已驗收。主機生成與批次渲染同時運行時，第一輪模型加語音等待約54秒、第二輪約24秒，操作片沒有把這段加速偽裝成即時反應。

## 驗證

114 項後端及 20 項前端測試通過。新增測試核對遠端不啟動生成、串流與 Range、模組權限、過期來源／損毀素材拒絕、12職類39任務及8講師覆蓋。錄影用全新獨立資料庫、示範教師及學員，不改正式學員紀錄或能力核定。

講師影片發布前逐檔核對來源、角色模型、性別、檔案長度與 SHA256；音訊、編碼與視覺抽查結果另存交付驗證。GitHub Pages 提供入口及公開操作片，登入、記錄與連續語音依然由使用者持續開機的同網路電腦執行。
