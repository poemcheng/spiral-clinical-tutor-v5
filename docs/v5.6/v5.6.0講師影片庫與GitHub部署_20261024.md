# v5.6.0 講師影片庫、操作實錄與 GitHub 部署

本版將生成與播放分開：Windows 主機預先生成含男女聲的講師影片，主機或其他部署環境安裝公開素材後即可播放。手機、平板及其他電腦只需登入，不必有 Windows 語音引擎、Ollama 或 GPU 才能觀看既有影片。完整互動、登入及學習紀錄仍由使用者選定的同網路主機提供，GitHub Pages 是入口及操作影片說明頁。

## 影片範圍與教學目的

依使用者確認，以合適講師配對全部 9 個情境、39 組職種任務。另有 9 組社工支援角色的家庭溝通與資源協調補充導讀，共 48 組、各 3 段影片。不是每位講師都講解每一職種。

每組分成情境與觀察目標、本職類任務導讀、交接與練習目的。影片為 Level 1–5 共用導讀，當級難度、個人弱項及評量仍依原本教案文字與會談設定；不把共用影片冒充個人化生成。模組依原有累積學習權限開放，前級教材繼續保留。

已有模型的職種由相應專業角色導讀。語言治療、聽力、呼吸治療、醫事檢驗及臨床心理等尚無獨立模型的職種，由醫師角色做跨域案例導讀，明示本職類技能需由對應專業教師核對；不把醫師模型改稱其他專業資格。社工只做家庭溝通與資源協調補充，不代替醫事技能教學。逐項配對見 [覆蓋對照 CSV](講師影片覆蓋對照_20261024.csv)。

腳本以既有教案背景與職類任務為依據，保留教學來源及指紋。導讀不加入新檢查、藥物劑量、療效保證或未完成處置，不把缺少資料當正常。標示「來源、角色界線與教學目的已核對；臨床教師正式核定待完成」。病例、院內流程、診斷版本與實際技能仍須教師依現行規範審閱。

查核參照：[ASHA 成人吞嚥障礙與跨專業評估](https://www.asha.org/practice-portal/clinical-topics/adult-dysphagia/)、[ACR／RSNA 病人教育：孕期醫療影像](https://www.radiologyinfo.org/en/info/safety-hiw_10)、[AWGS 2025 共識更新](https://pubmed.ncbi.nlm.nih.gov/41188603/)。AWGS 2025 將診斷簡化為低肌肉量合併低肌力，身體功能作為結果指標，因此本系統另標示 2019 歷史教案版本。這些資料用來確認評估、分工與個別風險溝通的界線，不代表本院教案已獲外部認證或所有歷史文字皆可直接當現行指引。

## 播放與版本核對

Step 3 預設顯示「已發布 · 可直接播放」，具原生控制列、playsinline、文字稿及教學目的。影片使用 H.264／AAC MP4、faststart，API 支援 Range，供 iPhone 等裝置分段讀取及拖曳。每次播放核對案例來源指紋、學員職種、所選講師、模型雜湊與模組權限；檔案校驗不符或未安裝會清楚顯示，不回退到另一位講師的影片。

遠端介面不顯示生成按鈕。主機本機可保留個人化生成，既有影片與來源仍保存為歷史版本。產生的個人化工作不會直接把學員資料上傳 GitHub。

## 在主機更新並準備公開影片庫

```powershell
.venv/Scripts/python.exe tools/build_lecture_library.py
.venv/Scripts/python.exe tools/verify_lecture_library.py --strict --enrich-voices
.venv/Scripts/python.exe tools/prepare_publication.py
```

建庫工具只讀教案與角色資料，不讀學員資料庫。腳本、來源或角色模型改變時建立新內容識別碼；既有已生成的相同版本可重用。管理者核對後，將完整程式碼與產生的 public-assets.zip、public-assets-manifest.json 更新至新的 GitHub 發行版本。已發布的素材保持不可變；後續新影片應建立新的發行版本並同步下載器版本，避免覆寫歷史包。

新部署取得同一版本程式碼後執行 `python tools/fetch_release_assets.py`，會下載並逐檔校驗素材，包括已生成的公開講師影片，不在 GitHub Actions 或手機上重新渲染。既有主機安裝與重啟前應備份學習資料。未發布的新生成影片仍只存在本機，需由管理者核對並更新發行包後，其他部署才會取得。

## 操作實錄

最新版實錄展示學員自評、五級教材、講師影片直接播放、一般及環景教材、180 格骨架分析、學員保存判讀、分支重練與安全結局、連續語音、決策及 SBAR、教師逐格／分支／整體回饋，以及學員查看回饋。

操作畫面來自隔離測試帳號的實際操作，等待可剪短、閱讀畫面可延長；連續語音段按實際時間保留，明示使用合成輸入，並混入相同測試音源及實際角色語音。示範評分不是實際臨床能力核定。公開版隱去原始實拍及環景教材影像，保留操作控制、分析文字與流程；完整未遮罩實錄留在本機，原始教材及私有學習資料不放入公開素材包。
