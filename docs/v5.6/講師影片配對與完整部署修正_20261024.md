# v5.6.3 講師影片配對與部署修正

## 問題與原因

使用者在物理治療師的「營養師與物理治療師 SBAR 跨團隊溝通教案」看到影片尚未安裝的提示。實際上 v5.6.1 的 144 部影片皆已安裝；缺漏來自發行計畫只涵蓋新版九個 COURSE 情境，而介面仍能選取十九份舊教案。原先的覆蓋檢查也只比對九個情境，因此沒有發現這個缺口。

舊肌少症教案在選定後還會加入臨床版本提醒，影片建置若只雜湊原始 registry 內容，會與訓練快照不相符。此版在影片計畫與驗證時使用同一個教案調適程序，保留原始病人、角色與版本比對，沒有把不同病例當成同一份影片。

## 本版修正

- 預生成範圍擴大至全部二十八份內建教案、103 組適用職種任務。原九份社工導讀保留，合計 112 組、336 部有聲 MP4。
- 舊教案每個職種配對適當講師；無專屬人物的職種明示跨域導讀，專業技能仍由相應教師核對。男女聲沿用嚴格性別檢核。
- SBAR 的物理治療師導讀聚焦活動能力、運動耐受度、疲勞觀察，以及與營養師的資料需求及共同追蹤。其他職種依各自的回報與協作責任撰寫，不補造病歷數值。
- API 先確認已解鎖模組的實體檔案、大小及 SHA256，才宣告可播放。缺檔、版本不符、尚未製作與整庫未安裝分開提示。
- 原選講師沒有影片時，只在同一教案、同一來源版本、同一職種的可用影片內改用適當講師，畫面明示改用原因；不覆寫既有訓練或角色選擇紀錄。
- 遠端講師選單只列出實際可用的人物，空清單不再誤顯示所有尚未發布的角色。新增來源或教師自訂教案若尚未發布影片，會明確說明，文字教案仍可閱讀。

## 發布與驗證

全部影片在 Windows 本機以既有 Three.js 蒙皮角色、實際語音音量與口型連動、HyperFrames 0.8.185 製作。沿用既有 960×540、24 fps 教學片格式；影片只提供情境與任務導讀，詳細教材、逐格證據與學習歷程仍在登入後的平台。

發行素材包只納入允許清單、影片目錄實際引用的公開 MP4／文字稿、角色及執行資源。原始教材、EPA 原圖、個人紀錄、帳號、密碼與私鑰均排除。已凍結的舊發行包不被覆寫，新安裝預設取得 v5.6.3 的校驗素材。

自動測試涵蓋全部可選內建教案的計畫、舊 SBAR 各級版本一致性、缺檔與損毀檔不宣告可播，以及同來源講師替代。另檢核所有影片的檔案雜湊、H.264／AAC、時長與音軌能量。聲音以量測及聲線中繼資料核對，未宣稱人工逐部聽完。

使用者已開始的 SBAR 訓練保持原教案與進度。透過同網路 HTTPS 驗證三個模組均回傳 Range 206；瀏覽器已實際完整播放第一段，並以手機尺寸檢查第二段。尺寸測試不等同實體 iPhone 驗收。

原 v5.6.1 完整操作影片仍保留，流程適用本版。GitHub Pages 提供同網路登入入口；持續運作的後端與個人資料仍在本機主機，並非由 Pages 執行。

## iPhone EPA 載入修正

原頁面會在初始化時載入原片及多個講師片的中繼資料，並把環景播放器建立、影片定位和影格初始化放在同一流程。此版改為 JPEG 影格優先，預設選第一張代表格，避免直接停在原片開頭的黑畫面。原片和講師片均按播放後才載入；環景 WebGL 無法建立或 Safari 尚不能定位影片時，不阻斷逐格圖片、註記與前後格控制。

解析請求加入逾時、取消舊請求、重試按鈕及圖片載入錯誤提示。一般教材播放器與 EPA 初始化互不等待。自動測試驗證未點播放不啟動原片／WebGL、Safari 定位拋錯仍可換格、逾時可重試。

使用者已於 iPhone Safari 回報能看到圖片並正常換格；另以 390 像素實測床邊照護第 300→301 格及原圖切換。

## 醫院／學校 Microsoft 365 寄件

管理設定新增 Microsoft 365 與 SMTP 的服務選擇。Microsoft 365 使用組織應用的 client credentials 與 Microsoft Graph `sendMail`，不要求填寫個人 Outlook 密碼。需院校 IT 提供：寄件信箱、Tenant ID、Client ID，以及直接在本機管理頁填入的應用程式密鑰。

請 IT 在 Entra 註冊專用應用，核定 Graph `Mail.Send` 應用程式權限及可用寄件信箱範圍。此版本沒有替院校建立應用或授予組織權限。密鑰加密保存在本機資料庫，API 不回傳密鑰或權杖。學員仍需輸入收件信箱並同意寄送；只有 Graph 回傳 202 才記錄服務接受，接受不等於最終送達。此版完成模擬授權與真實 PDF 附件結構測試，正式寄件待院校提供設定。

IT 參考：[Microsoft Graph 寄件權限與附件規格](https://learn.microsoft.com/en-us/graph/api/user-sendmail)、[組織應用 client credentials 流程](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-client-creds-grant-flow)。

## 乾淨安裝的教案結構補齊（v5.6.3）

v5.6.2 發布後的獨立安裝檢查發現，七份既有平台教案的結構僅存在本機 Markdown，未進入原始碼。v5.6.3 將這些虛構教案的系統資料作為 Python 內容種子發布；不包含原始文件、EPA 圖片或學習紀錄。保留本機 Markdown 的覆寫優先序。新增回歸檢查在沒有原始 Markdown 的目錄載入全部 28 份教案，並比對 112 組講師來源雜湊，確保 336 部影片都可正確配對。舊發行包保持凍結。
