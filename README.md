## 啟動

從GitHub下載或clone後先安裝Python依賴，再取得有SHA256檢查的公開執行素材：

```sh
python -m pip install -r requirements.txt
python tools/fetch_release_assets.py
python tools/prepare_voice.py
python -m pip install -r requirements-pose.txt
python tools/setup_pose.py
npm ci
npm run build
```

Windows雙擊 `run_windows.bat`，本機網址為 **http://127.0.0.1:8705**。首次本機管理員為user／1234，既有帳密不重設；學員及教師由管理員建立。從4.5.1本機升級時原始資料夾保留，移轉前須使用一致性備份。

公開主機使用Docker Compose及獨立強密碼、HTTPS、持久化儲存，詳見[部署說明](docs/v5/部署說明.md)。GitHub Pages不能執行Python後端與Ollama。本儲存庫是可部署程式碼，沒有宣稱此GitHub網址本身已執行完整後端。

## 素材與範圍

公開素材包含人物、前端執行套件及衍生教學資料，不含學員資料、資料庫、密碼、來源PDF／Excel、實拍影片或360代理影片。教材管理者另提供其授權的教材檔案；缺少媒體時介面會明示。一般影片與四支本機360影片皆可逐張分析；一般影片保留構圖比例，環景才使用選定視角。兩部肌少症影片各有13段步驟目的與解說，並可選擇人物範圍；關節可見性、二維投影角度、動作片段及意圖候選與替代解釋供學員判讀。情境、職類視角與臨床標準解析仍待教師核定。

指標與題目為平台依職類框架改編的教學草稿，數量與自評切點是本系統課程設計；不宣稱為經驗證量表、臺灣執業標準或院方正式核定成果。自評、客觀練習及教師核定分開保存。

最新版完整操作實錄位於本機交付的 `docs/v5.3/v5.3.2-full-workflow-local.mp4`，約6分31秒，57章節與中文字幕，涵蓋學員六階段、教師逐格／整體回饋及學員查看。[章節索引與錄製範圍](docs/v5.3/v5.3.2完整操作實錄_20261023.md)。另有v5.3.2功能導覽位於本機交付的 `docs/v5.3/v5.3.2-operation-guide-local.mp4`，約2分51秒，示範五級教案、一般影片的步驟目的、人物範圍、逐格判讀、教師回饋及學員查看，另附中文字幕。影片由實際畫面擷取剪輯，含授權實拍教材，未放入公開素材包。舊v5.3.1影片保留為歷史紀錄。從公開原始碼安裝時，素材下載維持相容的v5.3.0基礎包，再以上述npm指令編譯目前版本。Windows角色語音優先使用PowerShell 7及已安裝的繁體中文男女聲；缺少對應性別會明示錯誤。

本版五級教材各有2項學習活動，累積提供2、4、6、8、10項活動；各級皆可保存判讀與教材快照。一般影片由Level 3、環景由Level 4、逐格骨架解說由Level 5開放，與自評互動難度獨立。影片根目錄可用VIDEO_LIBRARY_DIR指定；有授權原始影片時，可執行python tools/index_teaching_videos.py重新核對固定教材目錄。

## 開發與驗證

```sh
npm ci
npm run build
python -m unittest discover -s tests -v
```

本機Python 76項與前端7項測試通過，包含五級累積教案、一般影片權限、來源綁定及回饋快照。肌少症一般影片另完成22秒、528格的模型與瀏覽器流程驗證；完整影片尚未逐格驗收。Level 5教師逐格觀察回饋、不可覆寫的歷史、影片版本快照及學員端回饋顯示，不改變正式分數及Level。13位角色使用CC0 MakeHuman立體網格、163骨架與8種表情，不再以平面人像螢幕呈現。瀏覽器已完成兩輪真實MediaRecorder錄音→Whisper辨識→gemma4:12b案例回覆→中文TTS播放→接續收音的自動測試；音源為明示的合成測試語音，未測實體麥克風。實際gemma4:12b已驗證放射師→物理治療師兩輪對話；另以合成學員實際完成8輪訓練後，瀏覽器驗證自評Level2與累積Level5、360視角、逐格定位及紀錄保存。證據在 `docs/v5/` 及 `docs/v5.3/`。操作導覽由實際操作截圖組成，非連續錄影。

Docker Compose設定解析通過，但本機Docker Linux引擎未啟動，尚未完成容器建置及雲端推論驗收。Linux目前支援文字互動與既有影片；中文TTS與虛擬講師即時合成仍依賴Windows。

職類框架來源、版本與限制見[文獻核對紀錄](docs/v5/literature-search-log.json)；院徽來源見 `frontend/assets/hospital-logo-source.json`。素材與框架各自保留其權利；公開此程式碼不表示取得對第三方素材的額外授權。
