# 電腦圖學教學實踐：框架與操作

## 來源與範圍

改編依據為教師的「電腦圖學合作學習學習單（零件建模任務）」P1與「組合設計任務」P2，以及附件迴旋梯智鏈的六階段訓練與教師覆核框架。P1、P2來源識別與連結在 `backend/graphics_curriculum.py`，介面「課程與評量依據」可查閱。未下載或發布學生問卷、名單、私人原始教材、醫療資料或既有平台密碼。

教學主體是CATIA參數建模、組合約束、設計意圖與合作學習，不把前次對話中的資料庫管理課程或臨床規準套入。示例任務及週次為本次平台改編草案，仍須授課教師確認。

## 十八週建議配置

| 週次 | 任務與概念 | 個人與合作證據 |
|---|---|---|
| 1–2 | 讀圖、功能、幾何特徵、草圖基準 | 前測、自評、事前規劃 |
| 3–4 | 約束、特徵順序與設計意圖 | 個人模型、截圖、問題與解法 |
| 5–6 | 尺寸依存、鏡射、穩健修改 | 預測、尺寸擾動、模型互換與反思 |
| 7–8 | 組合架構、基準零件與配合 | 個人組合策略、約束說明 |
| 9–10 | 自由度、過度約束、干涉與間隙 | 預期運動、操作檢核與模型證據 |
| 11–12 | 零件替換、模組化與可交接性 | 同儕策略、替換結果與共同決策 |
| 13–14 | 自選專題需求與架構 | 教師確認範圍、個人設計論證 |
| 15–16 | 變更需求與策略整合 | 個別責任、交接、反例及驗證 |
| 17–18 | 無AI新情境、發表、反思與覆核 | 遷移測驗、個人說明、下一輪補強 |

每輪有一題前測與一題遷移選擇題，加上開放式理由；題數不足以代表已驗證的概念量表。正式研究應另建等值題本、延宕測驗與評分者程序。

## 學生操作

1. 管理員建立帳號；教師或管理員建立小組，成員順序決定輪替角色。
2. 登入選擇任務、小組與支持起點。無小組時明示個人練習。
3. 完成自評與前測。自評1–5是信心，支持層級1–5是提示強度，均不是教師正式分數。
4. 說明功能、幾何與預計步驟。操作前先留下計畫。
5. 在CATIA實作，記錄問題、解法、設計意圖與變更預測，上傳至少一個證據檔。
6. 合作互換：分享個人實作給本組、下載同儕附件，於CATIA修改並回報結果；在本輪另傳結果截圖或檔案。記錄共同決策與AI建議採納／未採納。
7. 獨立完成新情境概念題與解釋。此時平台停用提示，但無法監控外部AI、聊天或實際考場。
8. 完成技能、概念、合作反思及下一輪行動，提交教師覆核。提交後不可改寫原始證據，補強另開一輪。
9. 教師保存回饋後可重新登入查看，下載JSON。小組分享可撤回；已被同儕下載的檔案無法遠端收回。

「儲存草稿」是明確保存按鈕，不是自動儲存。未保存離頁會提示。儲存衝突時應先保留文字再重新載入，避免覆寫另一個分頁的資料。

## 教師與管理員

教師：查看學生完整歷程、原始附件、提示來源與任務快照；下載模型後在CAD軟體核對。四構面分別給0–3或未評，引用依據並指定補強。核定層級為課程內教師判斷，不由自評、觀看或提示次數換算。覆核追加保存，不覆蓋舊判斷。

教師編案：從「教案編輯與發布」填寫功能條件、目標、擾動任務及不同情境的前後測。保存草稿不影響學生目錄；發布才開放。已開始的訓練保存當時題目、答案、規準與SHA256，發布新版不改變舊紀錄。

管理員：建立學生／教師／管理員帳號與小組。管理員帳號不能代教師讀取或核定個人訓練；同一位人員若需教學操作，應使用獨立教師帳號。班級規模部署目前採單一課程站台，教師可查看站內學生，尚未實作跨院校或多租戶隔離。

所有帳號可在帳號設定變更密碼；更新會撤銷此帳號所有既有登入。沒有公開Demo共用密碼，也沒有遷移臨床帳號。

## 核心資料模型

- 共用原有 `Store` 的users、logins、雜湊密碼、SQLite交易與鎖。
- graphics_teams / graphics_members：分組與輪替順序。
- graphics_trainings：個人訓練、任務與規準快照、六階段、版本與狀態。
- graphics_artifacts：附件名稱、隨機儲存鍵、位元組數與SHA256；下載時校驗。
- graphics_hints：問題、回覆、層級、規則或模型來源。
- graphics_reviews：教師、構面分數、證據、後續行動與核定。
- graphics_events：個人階段提交、草稿、分享、附件、提示與覆核事件。
- graphics_lessons / graphics_lesson_versions：教師自編教案、編輯版本與發布版本。

事件與快照支援追溯，但同一資料庫管理者仍能修改資料；未宣稱密碼學防竄改或已通過ISO驗證。完整歷程JSON含個人作答，研究匯出後仍需正式去識別化程序。

## 能力邊界

- 原生CATIA檔案可保存、受控下載與校驗，不會在伺服器執行、解析特徵樹或自動評定尺寸正確性。
- 互動概念實驗僅用簡化孔位依存及滑塊X方向自由度說明。匯出的concept-lab.txt明示此範圍，不可替代真實CAD操作。
- 文字鷹架可離線規則運行；本機Ollama選配尚須用實際安裝模型驗收。沒有把規則提示偽裝為生成式AI。
- 原有醫事虛擬人物、EPA影片、SBAR、語音、臨床總分及雲端備份，不在新的課程入口出現；未製作電腦圖學講師影片或語音角色。
- 本輪已實作可執行核心與示例教材；正式教學的案例庫、專題核定及評分校準由授課教師補充發布。
