# 第五版 5.1.0：語音與沉浸場景

原介面曾等待LiveKit連線25秒後逾時。學員語音改走有登入驗證的本機HTTP API，無須先加入LiveKit房間。LiveKit保留為選用的教師收聽服務，沒有宣稱其橋接逾時已修復。

Chrome／Edge允許麥克風後，以MediaRecorder錄音，停頓約1.3秒結束一輪；本機faster-whisper base / CPU int8辨識並轉成繁體中文。可先確認文字再送出，或自動送出並在聽完回覆後接續聆聽。Windows zh-TW TTS回覆的音訊振幅同步驅動嘴形與說話狀態。原始錄音只在請求記憶體解碼，不留存音檔。

每段最多60秒、8MB，限本人進行中的Step 4訓練。教師不能代學員錄音。拒絕權限、裝置不存在、占用、模型未安裝與辨識失敗會顯示具體原因；等待權限20秒後釋放介面。停止對話會取消待處理結果。內嵌瀏覽器可能沒有麥克風權限提示，請改用Chrome／Edge。

## 沉浸場景與影片

互動採用three.js診間、照明、家具、攝影機與可點選情境標記。角色沿用擬真人像，加入眨眼、細微呼吸與語音嘴形；人像是3D場景內的平面，並非完整立體掃描或真人表情追蹤。AI回覆加入口語與輪流發言約束，仍依案例來源與指定職類回應。

四部已上傳VR360影片可切換至球面投影主場景，支援環顧、播放、全螢幕與逐格觀察。影片的臨床情境及職類對應待教師核定，不會因切換場景新增病歷。原始影片與代理檔保留在本機，未公開上傳。

新生成的講師MP4由共用three.js場景渲染，另附可拖曳環顧的3D講師教案，支援分段文字、音訊及嘴形連動。既有影片保留，可重新產生新版。

## Level 5全教材體驗授權

授權涵蓋12職種、全部適用情境、三種教案路徑與Level 1–5學習資源，不捏造完成輪數、熟練度或教師核定。起測題本為Level 5；自評後的互動難度仍依實際作答分流，教材解鎖維持Level 5。帳密只提供給使用者，不放入公開程式或素材。

另建體驗帳號：`python tools/create_demo_learner.py <username>`，由終端機提示輸入新密碼；工具不重設既有帳號。

## 安裝與驗證

Windows的`run_windows.bat`會檢查套件並在首次下載本機語音模型。手動安裝：

```sh
python -m pip install -r requirements.txt
python tools/fetch_release_assets.py
python tools/prepare_voice.py
```

模型依[SYSTRAN faster-whisper](https://github.com/SYSTRAN/faster-whisper)使用方式安裝，首次下載後離線推論。PyAV固定16.0.1，避免較新版本移除metadata_errors參數的解碼問題。中文TTS及即時講師影片生成仍需Windows語音。

本機56項測試通過。瀏覽器驗證語音檔辨識、AI角色回覆、音訊播放、3D場景、VR360媒體、逐格保存及互動講師教案。40.77秒three.js講師MP4已實際輸出；HyperFrames檢查通過，30/30文字對比檢查通過，另有時間軸結構與滿版畫布的非阻擋警告。實體麥克風收音仍依使用者瀏覽器及裝置授權。
