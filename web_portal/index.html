迴旋梯智鏈

連上同一個網路，使用手機或電腦繼續學習。

登入訓練平台

請先讓主機保持開機，並將這部裝置連上主機所在的 Wi-Fi 或區域網路。

帳號與密碼會在您自己的訓練主機輸入。學習資料保存在主機，GitHub 網頁僅提供連線入口。

首次使用手機語音

  1. 從主機管理者取得 本機 CA 憑證。
  2. 在手機系統設定安裝並信任此憑證。iPhone 安裝描述檔後，還需在「關於本機 → 憑證信任設定」啟用；Android 在「安全性 → 安裝憑證 → CA 憑證」。此憑證只應安裝在您信任的教學主機所屬裝置。
  3. 前往上方 HTTPS 登入頁，登入後按「我要對話溝通」，允許麥克風。

連線不成功時

確認主機上的同網路啟動器已執行，防火牆允許 TCP 8765，且 Wi-Fi 沒有開啟訪客裝置隔離。主機 IP 改變時，請輸入新的位址。
