登入訓練平台

請先讓主機保持開機，並將這部裝置連上主機所在的 Wi-Fi 或區域網路。

帳號與密碼會在您自己的訓練主機輸入。學習資料保存在主機，GitHub 網頁僅提供連線入口。

iPhone 首次連線

請使用獨立的 Safari，不要從 ChatGPT 或 LINE 的內建瀏覽器開啟區網網址。

  1. 下載這台教學主機的 iPhone 憑證描述檔，允許下載後到「設定 → 一般 → VPN 與裝置管理」安裝。檔案只有本機 CA 公開憑證，沒有 MDM 管理、帳號或私鑰。
  2. 到「設定 → 一般 → 關於本機 → 憑證信任設定」，啟用 Clinical Tutor Local Network CA 的完整信任。只下載或安裝描述檔，還不足以啟用 HTTPS 信任。
  3. 開啟手機連線與麥克風檢查，確認主機版本及收音後再登入。

Android 或電腦可使用 CA 公開憑證。憑證只應安裝在您信任的教學主機所屬裝置；停止使用時可移除描述檔。

Apple：手動安裝的憑證需要另行開啟信任

連線不成功時

如果 Safari 仍然連線逾時，請在 iPhone「設定 → Wi-Fi → 此網路右側 ⓘ」核對 IP 位址是否與主機同一子網路。相同 Wi-Fi 名稱仍可能受訪客或 AP 裝置隔離影響；請將手機的 IP 與 Safari 錯誤文字提供給主機管理者。主機需持續開機，防火牆需允許 TCP 8765。主機 IP 改變時請更新上方位址。
