# v5.7.1 外網測試部署與加密備份

本版以既有 Windows 主機與同一份持久化 SQLite 提供跨 Wi-Fi、行動網路登入。外網 TLS 由 Cloudflare Quick Tunnel 提供，不需安裝本機憑證。Quick Tunnel 是測試入口，沒有穩定網址或可用率保證；主機重新啟動後可能更換網址。長期正式部署需改為有固定網域的具名 Tunnel 或雲端主機。本機必須保持開機、連網與服務運作。

## 啟動與管理

先執行 `tools/start_lan.ps1`，再執行 `tools/start_internet.ps1`。既有目前使用者登入 Windows 的啟動捷徑會依 `runtime/internet-settings.json` 的 enabled 設定接續啟動外網及備份服務。此方式在使用者登入後啟動，不等同未登入時的 Windows 系統服務。

管理員登入後，從管理設定進入「外網連線與加密備份管理」，查看最新外網網址、最近成功的本機與 GitHub 備份時間及同步錯誤，並可要求立即備份。外網入口的更新只發布公開 URL、時間與測試狀態；學習資料不放入公開入口。

## 外網語音與權限

學員使用 HTTPS 下既有的連續收音、停頓偵測、STT、Ollama 情境回應與相同性別 TTS。語音資料及對話經同來源登入 API，保留既有取消、中斷、輪替和學習紀錄。外網服務不宣告區網 LiveKit RTC 可用；不把內網 UDP 地址當成外網可連地址。教師仍可查看持續更新的對話逐字稿、影格觀察、報告與保存回饋。外網圖片、影片及教材 API 仍驗證登入身分及訓練權限。

## 備份範圍與週期

每15秒檢查資料庫／WAL變更；有變更才建立 SQLite backup API 一致性快照。備份包含帳號密碼雜湊、學習歷程、對話、教師回饋、自訂教案、完整骨架分析結果與註記，以及已設定的寄件加密金鑰。還原快照會使舊瀏覽器登入失效，但保留登入歸屬與學習證據。

本機快照存放在 `runtime/encrypted-learning-backups/`，逐檔分為最多8MiB片段，壓縮並加密成內容定址物件；相同內容重用既有加密物件，本機快照使用硬連結，GitHub只新增變更物件及加密索引。加密索引驗證檔案、片段順序及SHA256。完成後解密讀回、核對檔案清單與資料庫 integrity_check / foreign_key_check，成功才更新狀態。GitHub每5分鐘同步新的已驗證快照；斷網失敗會保留本機備份並重試，不顯示成功。

私有目的地為 `poemcheng/spiral-clinical-tutor-private-backups`。上傳前若能匿名讀取目的儲存庫，拒絕上傳。儲存庫只接受 .enc 加密索引／片段及不含個人資料的README。解密金鑰位於 `runtime/secrets/backup-recovery.key`，SSH私鑰位於同目錄；兩者均不進入備份或GitHub。寄件金鑰如有設定，則包在外層加密備份內。

可重建的JPEG影格、PNG渲染及生成影音快取不進入學習資料快照；完整骨架result.json與教師／學員註記仍保留。共用原始教材、約12GiB既有EPA影格及原始影片仍由本機保存，不在學習資料GitHub備份中。程式與公開可散布素材由既有公開儲存庫／凍結發行包保存；新增教師教案以私有資料庫備份保存，未經審核不自動公開。大量原始素材需另行做檔案層備份。快照與Git歷史會累積，正式長期運作應設定組織備份保留與儲存容量策略。

## 還原

以 git clone --depth 1 取得私有儲存庫的 current/index.enc 及 objects/，搭配本機解密金鑰，將儲存庫根目錄作為 SNAPSHOT_DIRECTORY。舊版v1快照的index.enc與part檔仍可直接還原。先執行：

```
python tools/encrypted_learning_backup.py verify SNAPSHOT_DIRECTORY BACKUP_RECOVERY_KEY
python tools/encrypted_learning_backup.py restore SNAPSHOT_DIRECTORY BACKUP_RECOVERY_KEY NEW_EMPTY_DIRECTORY
```

還原只接受新的空白目錄，完成完整性核對後才置入資料；不覆寫正在使用的訓練。資料庫可搭配相同程式版本及原有共用素材還原。請將解密金鑰另存於管理者控制的離線備份，遺失金鑰便無法還原GitHub的加密資料。

參考：[Cloudflare Quick Tunnel 的限制](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)、[GitHub單一儲存庫Deploy Key](https://docs.github.com/authentication/connecting-to-github-with-ssh/managing-deploy-keys)。
