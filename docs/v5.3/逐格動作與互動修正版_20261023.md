# v5.3.1 逐格動作與互動修正版

依2026-10-22至23使用者補充修正，最新明確說明優先於舊需求稿。保留既有教案快照、學員作答、教師核定與歷史影片。

## 學員分析 → 教師回饋 → 學員查看

1. 學員登入、選職種與情境，完成本次登入自評，進入「影片與情境學習」。累積教材Level 5才開放骨架分析；自評互動Level獨立。
2. 選擇已安裝的360影片，調整人物視角，設定開始／結束秒數，按「開始逐格骨架分析」。單次最多300秒，可選完整影片；每份分析固定視角，另選視角須新建分析。
3. 本機將等距柱狀球面影片轉成640×480平面視角，以MediaPipe Pose Landmarker Full逐一處理區間內原始影格，保存33點位置、可見性、投影角度、局部軌跡及動作片段。沒有可靠骨架的影格也會保存狀態。
4. 使用上一個／下一個分析影格或滑桿逐格檢視。可見關節才計算角度；像素位移速度不是實際身體速度。候選骨架P編號不代表真實身分、職類或實際人數，多人重疊或重複偵測須人工核對。
5. 動作意義提供「可能解釋、影像依據、替代解釋、待核對資訊」。例如手腕高於肩部可能是示意、發問或取物，不能直接判定求助。沒有足夠資訊就明示無法確認。
6. 學員選取分析影格後填寫本格觀察並保存；系統綁定影格、時間、視角、來源影片雜湊、模型雜湊與結果雜湊，禁止將不同分析／視角混接為同一份證據。
7. 教師登入工作台，選同一筆訓練的「監看／覆核」。可開啟完整分析頁，逐格檢視及播放原始360影片和現場語音，再填寫具體回饋。
8. 教師回饋另存且保留歷程；舊版本衝突回傳409。學員回「影片與情境學習」即可看到教師姓名、時間及回饋；成果頁也會呈現。形成性逐格回饋不改寫正式能力等級與分數。

## 自評Level與真正3D互動

自評Level控制互動壓力，教材Level控制資源解鎖，正式能力由教師另行核定。Level 5的定義不是只能指導虛擬學員；同儕指導保留為額外選修，不再要求先與虛擬學員對話或填寫PEARLS才能交接。新選取教案的第五級任務以困難互動為主；歷史教案快照保留。

| 自評 | 病患／家屬 | 職場同事 |
|---|---|---|
| 1 | 友善、有耐心、願意澄清 | 願意幫助新手，不責怪提問 |
| 2 | 合作，但有一個疑慮 | 先整理需求，再協作澄清 |
| 3 | 追問理由後才合作 | 要求專業依據與分工 |
| 4 | 保留、追問實際安排 | 忙碌強勢，對未準備的交接不耐煩 |
| 5 | 質疑空泛說明，不能立即取得合作 | 要求「你應該先確認」，被直接否定時可能質疑挑戰權威 |

第五級的初始保留、遭強迫時的抗拒，以不包含醫療事實的情境台詞確保呈現，並接續實際LLM回覆；套用規則及LLM版本一起保存。AI承接學員實際用語；傾聽、具體依據及尊重分工可逐步降低抗拒，強迫或忽略疑慮則維持壓力。病例事實不得隨互動難度變更。臨床角色向醫事同事核對「病人的資料」，不把學員當病人問飲食或運動。

人物使用真正蒙皮人體網格與163骨骼，支援環繞觀看、實際音訊驅動嘴形、眨眼及小幅說話手勢，並依難度呈現友善或保留姿態。現階段為MakeHuman合成人物，非真人掃描或專業演員動態捕捉。

## 男女人物聲音配對

Windows本機語音優先用PowerShell 7讀取已安裝的中文聲音。本機已實際使用Microsoft Zhiwei男聲、Microsoft Yating女聲。找不到指定性別時回報錯誤，不改用另一性別；音訊快取同時檢查文字、性別與語音政策版本，舊的錯配音檔會重新合成。

13個角色已逐一實際產生音訊並核對語音引擎回傳的性別。男同事與女病患亦各通過兩輪瀏覽器自動回路：Web Audio測試音源 → 真實MediaRecorder與停頓偵測 → 本機Whisper → 實際Ollama → 對應性別TTS → 播放結束 → 接續收音。這不等同實體麥克風或真人音質聽審。

## 安裝與驗證

```sh
python -m pip install -r requirements-pose.txt
python tools/setup_pose.py
npm ci
npm run build
python -m unittest discover -s tests -q
npm run test:ui
python tools/check_interaction_difficulty.py
```

骨架依賴與公開模型只需安裝一次；影片及衍生骨架留在本機runtime。模型固定SHA256：`5134a3aad27a58b93da0088d431f366da362b44e3ccfbe3462b3827a839011b1`。模型能力與API參考：[Google Pose Landmarker Python](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python)；限制參考：[Google模型卡](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf)。

本機實測四部影片各5–7秒、每段60格；四段有候選骨架的影格依序為60、54、60、60。這是選定視角的技術處理結果，未標註真值，不是準確率，也不表示四部全長臨床解析已完成。介面另實測第二部影片-30°視角：60格中51格有候選骨架，並完成第151格的學員判讀與教師回饋。

71項Python測試與5項前端測試通過。測試資料置於隔離runtime，不加入實際學員的正式作答或分數。臨床標準解析、題目與量尺核定、實體麥克風、雲端完整部署及跨主機還原仍需分別驗收。
