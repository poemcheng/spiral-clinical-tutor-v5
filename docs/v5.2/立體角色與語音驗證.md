# v5.2.0：立體角色與連續語音自動驗證

2026-10-22 更新。依使用者指定，先完成模型與自動測試；實體麥克風驗收尚未進行。

## 已完成

- 13 位角色改用實際 GLB 人體網格、皮膚紋理、眼睛、牙齒、頭髮、衣物與骨架蒙皮。每位角色有 163 根骨架及 8 種臉部表情目標；互動人物與新生成講師影片共用此模型。
- 語音音量驅動嘴部；搭配眨眼、微小頭部與呼吸姿態。支援正面、側面、背面與臉部檢視；拖曳仍可環顧診間。
- 修正不透明皮膚與衣物的深度寫入，避免頭髮、眼球與衣服穿透。眼睛保留透明角膜，頭髮使用透明裁切。
- 舊影片與逐字稿保留。新影片使用不同 renderer 與模型雜湊，避免誤用舊平面人物影片快取。
- Step 4 提供「兩輪自動語音驗證（測試音源）」連結。測試使用正式錄音與辨識控制器、相同案例 AI 回覆服務、中文 TTS 及立體角色；測試對話僅暫存診斷工作階段，不寫入正式作答、決策或能力分數。

這批角色是具有寫實紋理與人體比例的合成 3D 模型，並非真人掃描或原始角色卡人物的精確數位分身；服裝是現有 CC0 一般服裝。

## 實際自動驗收

在本機瀏覽器重複完成兩次、每次兩輪的測試：

1. Web Audio 播放明示的合成測試句至 MediaStreamAudioDestinationNode。
2. 真實 MediaRecorder 編碼為 WebM/Opus，使用正式停頓偵測結束錄音。
3. 本機 Systran/faster-whisper-base 解碼與辨識，轉繁體中文。
4. 實際 gemma4:12b 依本輪案例回覆，沒有以假模型或預先寫好的回覆代替。
5. Windows 中文 TTS 合成並由 HTMLAudioElement 播放；擷取實際輸出音量驅動嘴形。
6. 第一段角色語音播放結束後，自動開始第二輪錄音；第二段播完自動結束測試。

第一次完整流程約 58 秒；兩輪錄音分別 72,921 與 78,719 bytes，角色語音分別 17.46 與 13.15 秒。正規化文字相似度為 100% 與 88.2%；第二句有「再／在」及漏字，原始辨識結果保留於本機報告。這是兩句控制音源的功能測試，不是一般中文辨識正確率評估。

本機 `python -m unittest discover -s tests -q`：59 項通過，包含 13 個模型的雜湊、網格深度、蒙皮權重、骨架、臉部目標與皮膚不透明材質，以及診斷驗證的登入、權限、輪數上限與正式資料隔離。

新講師影片已實際輸出：40.8 秒、960×540、24 fps、H.264 + AAC；HyperFrames check 通過，沒有執行錯誤，30/30 文字對比檢查通過。仍有非阻擋的既有分鏡結構／滿版畫布提示。已解碼檢查輸出影格，不只檢查檔案存在。

## 開啟方式

登入後開啟 `/static/character-3d.html` 可檢視所有立體角色。Step 4 的語音區有自動驗證連結，會帶入本輪 session 與角色。

本機驗收證據在 `runtime/verification-5.2/`，含兩次語音 JSON 報告、側背面截圖及輸出影片影格；不將執行期帳號、Cookie、錄音或資料庫公開。

## 素材來源與重建

幾何、皮膚、服裝與臉部目標來自 MakeHuman/MPFB 官方 CC0 素材：

- [MakeHuman 授權說明](https://static.makehumancommunity.org/about/license.html)
- [CC0 system assets](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html)
- [Face units 01](https://static.makehumancommunity.org/assets/assetpacks/faceunits01.html)
- [Visemes 02](https://static.makehumancommunity.org/assets/assetpacks/visemes02.html)

模型清單、來源與 SHA256 在 `data/characters/realistic-v1/manifest.json`。使用 Blender 4.5 與官方 MPFB 來源、素材安裝於 `runtime/human-build/` 後，可執行：

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' -b --factory-startup --python tools/build_realistic_characters.py
```

MPFB 工具程式與角色輸出素材的授權分開處理；公開包只包含生成模型，不包含下載的 MPFB 原始碼。一般安裝直接使用已生成且具校驗碼的公開素材，不必安裝 Blender。

## 驗收界線

實體麥克風、硬體裝置選擇與特定環境回音尚未驗收。依使用者回覆，這部分留待後續說話測試。預設語音對話已使用本機錄音與 HTTP 音訊路徑；教師的選用 LiveKit 橋接連線尚未完成驗收。Linux 的即時中文 TTS 仍需另行配置，本次自動驗收環境為 Windows 本機。
