# v5.6.1 帳號、報告與教師教案

本版完成使用者指定的本機帳號重建、Level 4 EPA 教材操作、師生回饋、PDF 報告、教師編案與網頁閱讀。GitHub Pages 提供公開操作影片與區網登入入口；訓練、資料保存、Ollama、語音與原始教材仍由持續開機的 Windows 主機提供。

## 帳號與管理

本機舊帳號、登入憑證、評量、訓練、對話、教師回饋與學習歷程已從使用中的資料庫移除，原語音與學員媒體一併移出使用位置。清除前的復原資料僅保留於本機私有維護備份，不放入 GitHub 或公開素材。

重建三個帳號：`demo`（學員）、`teacher`（教師）、`admin`（管理員）。三組隨機六碼密碼只交付本機使用者。Demo 授權為累積學習 Level 5、全部教材路徑，沒有預填成績、對話或學習證據。互動壓力仍由各職種本輪自評決定。

管理員可從帳號管理進入「管理設定」，設定最少與最多密碼長度，初始為四至六碼。政策僅影響之後的新建與重設；不改寫既有雜湊。本人修改密碼需要原密碼，成功後撤銷所有登入。新安裝本機管理員採隨機密碼；再次啟動會沿用既有啟用管理員，不額外建立預設帳號。

## EPA 與師生證據

累積 Level 4 可查看十一部一般／固定視角環景教材，共 104,637 格、76 段、88 張代表格。滑桿與編號可定位每張圖，骨架與原圖使用相同影格。學員保存可見動作、段落目的、可能解釋與資訊缺口；保存原片、分析及教案註記版本。

教師查看原始觀察、同格與相鄰格後另加具體意見，原學員文字保留。正式整體覆核、分支回饋與逐格回饋各自保存。學員重新登入可直接回看已完成訓練；新訓練與續訓仍需本次自評。

模型角度為二維投影，遮擋與人物配對可能失準；來源段落摘要不冒充逐字對話、病人意圖或臨床量測。EPA 詳細方法見 [EPA 逐格解析說明](EPA逐格解析與Level4更新_20261024.md)。

## 完整 PDF 與郵件

完成訓練後，成果卡與學習歷程提供報告入口，教師也能開啟該學員報告。內容含原訓練自評、前測、關鍵決策、後測、客觀練習綜合與教師評分。未評項目顯示待評，不補成零分。雷達只呈現有來源的職種自評，不把尚未核定的訓練分數造作成能力雷達。

另附職種能力證據、EPA 觀察與教師意見、SBAR、整體回饋、完整會談、來源雜湊與版本。前後測題本不同，不直接當成等值進步量。PDF 使用附 OFL 授權的 Noto Sans TC；網頁以相同 PDF 的實際頁面預覽，手機不需 PDF 外掛，亦可下載。

管理員在「管理設定」填寫實際 SMTP 主機、TLS 模式、寄件帳號與應用程式密碼。秘密以 Fernet 加密，金鑰只留本機 `runtime/secrets/`；公開程式碼與 API 不回傳密碼。私人備份工具包含復原所需金鑰，請由主機管理者保管。

學員輸入收件信箱並勾選寄送確認後，伺服器附上本人 PDF 寄出。沒有設定 SMTP 時回傳明確提示；只有寄件伺服器接受才記錄成功，最終投遞仍依收件系統。本次未取得實際寄件服務設定，僅完成失敗提示及模擬 SMTP 接受的自動測試，沒有宣稱外部郵件已送達。

## 教師編案與 Graphify 檢索

「教案與知識圖譜」可空白新增，或複製來源為教師教案。可編輯名稱、主題、適用職種、病人背景、目標、教材、角色任務、決策、評分與來源。先保存草稿，再發布；修改採版本衝突檢查並保留歷史。發布會出現在適用職種的選單，既有訓練仍保留原快照。自訂教案直接以網頁呈現；沒有預生成講師影片時不顯示錯誤的影片可用宣稱。

實際導入 [Graphify 官方專案](https://github.com/Graphify-Labs/graphify) 的 `graphifyy==0.9.95`，使用 `build_from_json` 建立有向圖。此版採本機結構化節點與明確詞彙共現，結合關鍵詞與圖鄰接檢索，回傳來源片段與圖譜；沒有使用外部 LLM 擷取或把文件送到雲端。

限定某輪訓練時，檢索原教案快照與該輪對話，避免新版教案取代原始證據。節點保留來源類型、ID 與內容雜湊；同詞共現不代表因果、診斷或正確答案，學員陳述與虛擬角色回答均需教師判斷。權限限定教師與管理員。

## 網頁教材與手機

教案 PDF、核心能力文件及教師自訂教案可直接網頁閱讀與搜尋；題庫仍限教師與管理員。來源讀取採固定允許清單，不能指定任意檔案路徑。

本機入口 `https://192.168.68.108:8765/login`。請同網路、獨立 Safari、已信任本機 CA；GitHub Pages 的入口可填目前主機位址。手機無法以 GitHub 網址直接取代此後端。主機 IP 改變時需重新產生對應 TLS 設定並更新入口。

本版以 390 像素瀏覽器尺寸實際登入、回看報告與切換 EPA，確認版面及請求成功。之前使用者已確認 iPhone 可看到版本及麥克風音量；本次實體 iPhone 的登入後 EPA 及連續語音仍需使用者回報。瀏覽器尺寸測試不等同實機測試。
