# v5.5.0 角色對應、連續語音與同網路部署

本版以這台 Windows 電腦為後端主機，GitHub Pages 為入口。手機與其他電腦須連上同一個可互通的網路，主機須保持開機。既有 SQLite、帳號與學習紀錄保留；公開包沒有資料庫、學員資料、私鑰、臨床來源文件或實拍影片。

## 已整合的功能與驗證範圍

|功能|採用元件|本版狀態|
|---|---|---|

## 本機與同網路啟動

在專案目錄執行：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-extended.txt
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start_lan.ps1
```

啟動器只採用已連線的實體網卡，避免斷線乙太網路位址被用作語音位址。HTTP 127.0.0.1:8705 與 HTTPS 8765 由同一個後端程序處理；LiveKit 訊號經同源驗證代理，隨機金鑰保存在忽略的 runtime 目錄。

目前主機 Wi-Fi 入口：**https://192.168.68.108:8765/login**。位址若因 DHCP 改變，重新執行啟動器並更新 GitHub Pages 的主機設定。入口網頁也可輸入新的私有網路 HTTPS 位址，設定只保存在該裝置。

首次由其他裝置連入，需使用者完成：

1. 在主機以系統管理員 PowerShell 執行 `tools/allow_lan_firewall.ps1`。規則只允許 LocalSubnet 連入 TCP 8765/7881、UDP 7882–7982；不關閉防火牆。
2. 從主機 `runtime/lan-tls/clinical-tutor-ca.cer` 取得本機 CA 公開憑證，核對與入口網頁提供的檔案 SHA256 相同，再於自己的手機/電腦安裝並信任。iPhone 安裝描述檔後，仍需至「一般 → 關於本機 → 憑證信任設定」啟用對該 CA 的信任。Android/電腦的憑證操作依系統版本而異。
3. 開啟 HTTPS 入口並允許網站使用麥克風。不要使用略過 TLS 警告作為驗收方式。主機與手機要能彼此連線，訪客 Wi-Fi 的裝置隔離可能阻擋連線。

目前主機未具系統管理員權限，Windows 已拒絕新增上述規則。服務端 HTTP、HTTPS 與 Wi-Fi HTTPS 健康檢查均成功；外部裝置連線及實體麥克風仍待上述操作後驗收。

GitHub Pages：https://poemcheng.github.io/spiral-clinical-tutor-v5/ 。它是同網路主機入口，登入與紀錄都在本機後端處理。公開 GitHub 網址不代表後端可從外網使用。

## 角色及會談檢查

登入後從角色檢視開啟 `/static/character-3d.html`，可逐位對照原卡與 3D、旋轉側面/背面及測試表情。角色縮圖使用真正對應的原角色卡。原卡及量測結果均保留 SHA256，歷史會談可解析目前的模型資料，原學習快照不被改寫。

Step 4 預設為本機 HTTP 連續語音；進階選項可選 LiveKit Agents。兩者使用同一套案例約束與男女聲選擇。切換或取消會清理收音與房間；虛擬人說話時可偵測持續說話並中斷。聲音測試由可追溯的合成音源送入實際 MediaRecorder / RTC 流程，不能取代真人口音、回音、網路與手機省電模式的驗收。

## 選配設定

PostgreSQL：先設定強密碼並啟動 `compose.postgres.yaml`，停止寫入後執行 `tools/migrate_postgres.py`。工具只接受空目標資料庫，使用一致性 SQLite 備份、交易及逐列比對；驗證完成後才設定 `DATABASE_URL` 切換。正式資料尚未執行此流程。

Piper：設定 `PIPER_MALE_MODEL`、`PIPER_FEMALE_MODEL` 及對應 `.identity.json`，內容需有模型 SHA256、zh 語言與 gender。模型授權與實際聲線需先核對。缺少正確性別不以另一性別代替。

xAPI：成果頁與教師詳情提供下載，API 為 `/api/sessions/{id}/xapi`，使用原有權限檢查。匯出使用穩定 statement ID 與匿名帳號識別，不夾帶對話或教師自由文字；尚未傳送至外部 LRS。
